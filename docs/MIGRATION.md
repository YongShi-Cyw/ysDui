# v2 迁移边界

迁移源固定为 `balloonui-main` 的提交 `d1ab3f3`。该版本的 93 个公开头直接使用平台 SDK 与 ATL/WTL 继承体系，不能安全地复制到 v2 公开 API。

v2 先固定三层依赖：`core` 不依赖渲染或平台；`render` 仅依赖 core；`platform-win32` 依赖前两者。所有后续控件按此顺序迁移：先将状态、布局和交互迁至 core，再把绘制变为 render 命令，最后在需要时接入平台原生能力。

原生编辑器、富文本、拖放、自动化和文件选择等能力属于平台后端。它们必须通过平台能力接口表达，不得将原生 SDK 对象放入公共方法签名。
